# Java Full Notes

A concise, structured collection of Java study notes covering core Java, object-oriented programming, exception handling, generics, collections, Java 8, multithreading, unit testing, Spring Boot, Spring Data JPA, Spring Security, and Spring Cloud.

## Overview

This repository is organized by topic and designed for quick reference and exam/interview preparation:

- `01_CoreJava/` — Java fundamentals, JVM concepts, data types, strings, keywords, garbage collection, enums, serialization, and object methods.
- `02_OOPs/` — Core object-oriented concepts: classes, objects, encapsulation, inheritance, polymorphism, abstraction, interfaces, and abstract classes.
- `03_ExceptionHandling/` — Exceptions hierarchy, try/catch/finally, throw/throws, try-with-resources, propagation, and suppressed exceptions.
- `04_GenericsAndWildcards/` — Java generics fundamentals and wildcard usage.
- `05_Collections/` — Collections framework, List/Set/Map implementations, queues, priority queues, iterators, comparators, and thread-safe collections.
- `06_Java8/` — Functional interfaces, lambda expressions, streams, optional, date/time API, and collectors.
- `07_MultiThreading/` — Multithreading basics, thread creation, synchronization, communication, deadlock, executor framework, futures, locks, atomic classes, and concurrency utilities.
- `08_Java-Unit-Testing/` — JUnit 5 and Mockito notes for unit testing Java applications.
- `09_Software Design Principles/` — Design patterns, SOLID principles, and architectural best practices.
- `10_SpringBoot/` — Spring Boot concepts, application development, and core features.
- `11_Spring Data Jpa/` — Spring Data JPA fundamentals, repositories, and persistence patterns.
- `12_SpringSecurity/` — Spring Security concepts, authentication, authorization, and security best practices.
- `13_SpringCloud/` — Microservices and cloud-native architecture using Spring Cloud.

## Usage

- Browse the folders for topic-specific notes.
- Use the markdown files to review concepts, examples, and interview preparation material.
- Ideal for Java learners, developers preparing for interviews, and engineers refreshing Spring and microservices knowledge.
